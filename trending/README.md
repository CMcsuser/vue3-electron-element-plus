# 🔥 GitHub 每日 Star 增长 TOP 3

本目录每天由 GitHub Actions 自动更新，展示当天 GitHub 上星数增长最快的前三个项目。

## 📄 文件说明

| 文件 | 说明 |
|------|------|
| [daily.md](./daily.md) | 最新一天的 TOP 3 trending 项目 |
| [SUBSCRIBE.md](./SUBSCRIBE.md) | 订阅说明——如何第一时间获取更新通知 |

## 🗓️ 更新频率

每天 **UTC 08:00**（北京时间 16:00）自动运行，抓取 [GitHub Trending](https://github.com/trending) 页面数据并更新 `daily.md`。

## 🚀 数据来源

- 官方 Trending 页面：<https://github.com/trending>
- 爬取脚本：[scripts/fetch-trending.js](../scripts/fetch-trending.js)

## 📬 如何订阅

请参阅 [SUBSCRIBE.md](./SUBSCRIBE.md) 了解多种订阅方式。
